A FEW THINGS TO KNOW

Before you
press play.

How do I install Audioly on Android?

Download Audioly.apk, open it, and approve the installation. If Android asks, allow “Install unknown apps” for the browser or file manager you used. Official releases install as Audioly.

Can I bring my Spotify playlists?

On Android, connect Spotify in Integration settings to access playlists and Liked Songs. Spotify supplies track and playlist information; playback is matched to a YouTube source. Audioly does not stream Spotify’s protected audio.

I’m using Audioly Dev. How do I move?

The public Dev channel is retired. Export settings and listening history from Dev, install Audioly, restore the backup, and sign in again. Keep Dev until you have checked your data. Downloads, local playlists and account sessions are not included in the backup. Early Dev builds have no update feed, so they need a one-time manual move.

Read the migration guide ↗
Is Audioly free?

Yes. Audioly is free to download and its source is available under GPL-3.0. Music and feature availability depend on the sources and accounts you connect.
