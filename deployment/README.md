# Audioly deployment

The templates support a Go party service and a static website behind Caddy.

- Website: `https://audioly.me`
- Party API: `https://api.audioly.me`
- Native service templates: `native/`
- Website source and invite page: `website/public/`
- Optional container templates: `vps/`

Configure DNS, TLS and server access for your own infrastructure. These files contain no deployment credentials, and publishing this source does not deploy it. Consult the backend README and review scripts before running them on a server.
